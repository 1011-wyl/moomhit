# 月下疑局 · Moonlit Werewolf

暗色月夜风格的本地 12 人文字狼人杀，镜隐迷踪板子、有警长。人物性格可编辑，使用你配置的 DeepSeek 模型。

## 启动与升级

需要 Node.js 22.13 或更高版本。首次安装执行 `npm ci`，随后运行 `npm run dev`，打开 http://127.0.0.1:4322/ 。也可双击 `启动游戏.cmd`。

升级后关闭原服务，再启动并刷新网页，**新开一局**。旧九人对局不能直接转换成十二人，保留为只读历史；开新局会把旧局归档。原 `.env.local`、人物设定和存档保留。

生产运行：`npm run build` 后 `npm start`。开发和生产服务不可同时占用同一端口。

## 玩法与操作

- 你坐在 12 号，可在准备页选择「我的身份」，也可随机。11 个 AI 的姓名、MBTI、性格与提示词可独立设置。
- 导演模式为全 AI，可配置完整身份阵容，选择盲视角或全知视角。
- 每段发言结束停留，点击「下一位 / 继续流程」才会推进，包含自己的发言、警上发言和遗言。你看不到的狼队密谈自动推进；可见密谈保留手动控制。夜间技能等非发言步骤自动进入下一项。
- 你的发言限时 90 秒，结束或超时提交当前内容，空白视为过。AI 发言支持逐字展示。
- 警长选举和放逐投票都使用**同一个 5 秒窗口**：AI 请求同时发起，你在倒计时内选择并确认。截止后未提交、模型失败或超时都弃票；不重试、不延长、不预先计算选票。选票截止后统一公布。
- 投票窗口不能暂停。其他阶段可暂停；进行中的普通模型回复会保留，恢复后用于原回合，避免重复调用。
- 顶部固定显示当前行动，白天显示行动座位，夜间只公开主持阶段，隐藏其他人的行动座位；投票显示倒计时和提交状态。
- 「规则演示」不调用 API，使用固定模板与策略，只用于体验流程。导演模式同样需要手动推进发言。
- 对局存于 `data/store.json`；私人笔记和输入草稿存浏览器。复盘展示身份、事件和简短决策摘要，不展示模型隐藏思维链。

## 本板子规则

3 普通狼人、1 觉醒隐狼、4 村民，魔镜少女、女巫、猎人、守卫各 1。暗牌、屠边：狼全灭好人胜，村民或神职全灭狼人胜。

觉醒隐狼与普通狼人互不相认、不共同密谈，普通狼人全部出局后获得狼刀。一局一次模仿其他玩家，可跳过等待以后夜晚；立即知道并伪装目标身份，当夜结束后获得对应技能：

- 魔镜少女：每夜查具体身份，不可重复查验。
- 女巫：只有一瓶毒药。
- 守卫：可以守住刀和毒，不可连续守同一人。
- 猎人：非毒死可开枪，当晚模仿后当晚出局亦按此处理。
- 狼人：取得刀权后，一次额外狼刀。
- 村民：无额外技能。

魔镜少女查已模仿的隐狼得到模仿身份，未模仿则得到觉醒隐狼。女巫全程不可自救，每夜最多一药，解药用完不再显示刀口。守卫可以自守、不能连守；同守同救的被刀者仍死。猎人中毒不发动；同夜刀毒命中按毒死处理。首夜死亡及白天出局有遗言，已确定胜负直接结算。

首夜技能完成后，所有人同时选择是否上警：AI 基于同一份报名开始时的信息并发决策，真人同时确认；全部完成后才公布名单，再进行警上发言、退水、警下投票，最后公布夜间死亡。报名不使用选举投票的五秒倒计时；失败时暂停并保留已确认选择，恢复后只重试未完成者。退水者不参与警长投票。单一候选人直接当选，无候选人警徽流失；平票一次 PK，再平票流失。警长决定顺/逆时针发言且最后归票，放逐投票为 1.5 票，出局移交或撕毁警徽。放逐平票一次 PK，平票候选人不参加第二轮投票，再平票或全弃票无人出局。

普通狼人可自刀、白天自爆；觉醒隐狼不可自爆。警上首次自爆延后竞选，第二次自爆吞警徽。普通狼队密谈后并发选择狼刀，以最高票决定；并列最高票在对应目标中等概率随机一次并保存，空刀不参与目标竞争，全部空刀则无人被刀。选择阶段不设五秒倒计时，发生请求失败暂停并保留已完成选择，恢复只请求未完成者。空刀计票为本项目明确约定，未标注为网易已证实细则。

规则来源：[网易镜隐迷踪介绍](https://langrensha.com/news/official/20231113/26904_1119726.html)、[网易角色及基础规则](https://langrensha.com/wanfa/guize/2017/10/18/26899_719311.html)、[网易赛事板子说明](https://langrensha.com/20260710/31012_1307230.html)。官方公开页面未列全的选举流程采用上述明确约定；手动推进与 5 秒并发投票是本项目按你的要求定制。非官方客户端复刻，无网易游戏素材或商标。

## 夜间反馈与速度优化

你确认查验后由本地规则直接计算结果，不等待后续 AI。主画面立即显示仅你可见的查验卡，本夜常驻，后续角色行动不覆盖结果。新一夜开始后可在「我的身份」回看历史。

技能请求只返回合法目标和简短决策摘要，保留原模型、思考能力与输出上限；无跨阶段预生成或历史摘要。自动阶段由请求完成触发，不再附加固定 0.8 秒等待。密谈结束后狼队基于相同的讨论快照并发选刀，部分选刀信息在收齐前不公开。

请求耗时记录在本地 `data/timings.jsonl`：任务类型、是否调用模型、总耗时和成功标记，不记录密钥、发言内容或身份。此日志不发送到外部；供应商网络和推理时间仍会影响实际体验。

升级时当前已经开始的旧夜晚保持原狼刀规则，下一夜起使用并发选择和随机平票；已确定的刀口不会因升级或刷新改变。API 支持 `signupChoice`（上警报名）与 `wolfChoice` 操作，携带选择阶段 ID 与目标；返回的 `wolfSelection` 只包含观看者合法的提交状态与选项。服务器保留阶段快照、部分选择和固定刀口以支持恢复。

## DeepSeek 配置与费用

保留现有 `.env.local`；首次使用可从 `.env.example` 复制。不要把真实密钥提交到 GitHub。

```dotenv
DEEPSEEK_API_KEY=在本机填写
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=填写你使用的模型名称
DEEPSEEK_INPUT_CNY_PER_MILLION=人民币元每百万输入token
DEEPSEEK_OUTPUT_CNY_PER_MILLION=人民币元每百万输出token
```

本地配置文件优先于进程环境。密钥只在服务端使用。保留你原本的模型名称和单价，不会为五秒投票自动换模型。单价应包含实际适用的最高输入/输出计费，供应商账单为准。

请求前按上限预留预算，返回 usage 后校正。投票需要一次性预留整批 AI 的请求预算，不足会在倒计时开始前暂停。超时被取消或失败而无 usage 的请求保留预估上限，因此显示费用可能高于实际账单。人物试聊有独立累计 5 元预算。

## 结构与验证

- `lib/game/engine.mjs`：12 人状态机、信息隔离、角色技能、警长与同时投票。
- `lib/game/engine-v1.mjs`：旧存档兼容读取及原版本回归测试。
- `lib/game/service.mjs`：本地保存、DeepSeek 调用、请求锁、投票并发和服务器截止时间。
- `lib/game/model-response.mjs`：完整 JSON 与合法行动校验，拒绝截断答案。
- `app/page.tsx`、`app/globals.css`：界面与倒计时。
- 同源本机 API：GET `/api/game` 返回合法可见状态；POST 支持 `start`、`step`、`advance`、`ballotVote`、`withdraw`、`explode`、`pause`、`archive`、`replay` 等。普通步骤校验 revision，投票校验轮次与服务器截止时间。

