# 月下疑局 · Moonlit Werewolf

暗色月夜风格的本地九人文字狼人杀。支持自定义人物性格、DeepSeek 玩家、规则演示、自动推进和对局复盘。

## 本地启动

需要 Node.js 22.13 或更高版本。

```powershell
npm ci
npm run dev
```

打开 http://127.0.0.1:4322/ 。也可以双击 `启动游戏.cmd`（首次使用先执行 `npm ci`）。只有本机可访问，不需要账号，不会部署到公网。

生产启动：`npm run build` 后执行 `npm start`。不要同时启动开发版和生产版，它们使用同一端口和存档。

## 现在就能玩

大厅 → 进入村庄 → 对手来源选择「规则演示」→ 开始对局。

规则演示使用固定策略和模板发言，免费、不访问模型，**不是 DeepSeek 的推理效果**。用于检查规则、输入、投票和存档。导演模式可让整桌自动演示。

## 手动接入 DeepSeek

项目已提供空白 `.env.local`；源码压缩包不包含该文件，解压后把 `.env.example` 复制为 `.env.local`。

```dotenv
DEEPSEEK_API_KEY=在本机填入密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_INPUT_CNY_PER_MILLION=填写实际适用的输入单价
DEEPSEEK_OUTPUT_CNY_PER_MILLION=填写实际适用的输出单价
```

- 模型名称可以改为你的小说智能体实际使用的模型。当前无法读取该项目，因此没有声称已经复用了旧密钥或旧配置。
- 单价单位为人民币元/百万 token，填入适用的最高输入/输出单价，包含长上下文或峰值时段；缓存命中暂按普通输入计费，估算可能高于账单。
- 更新配置后重启本地服务，在「对手来源」选择 DeepSeek。
- 默认单局预算 5 元，可在设置中调整。下一次请求保守估价超出余额时暂停；不自动切模型、不后台无限重试。
- 请求超时或连接失败可能已在供应商侧计费，因此保留该次请求上限的预留金额；实际费用以供应商账单为准。
- 角色试聊有独立累计 5 元预算，界面明确显示；只有手动选择 DeepSeek 并点击试聊才调用。
- 密钥只在服务端读取，不返回前端、不写入存档、不包含在打包源码里。不要把密钥发到聊天或提交 GitHub。

接口参考：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)，[官方定价](https://api-docs.deepseek.com/quick_start/pricing/)。真实联网效果、模型行为与实际单局成本需填入 API 后验证，本次开发没有付费调用。

## 功能

- 普通对局：你在9号座位，身份随机；身份练习：指定自己的身份。
- 导演模式：全 AI，开局前分配合法的完整身份阵容，可选盲视角或全知视角。
- 九个可编辑人物档案，MBTI、性格标签、自定义提示词、人物试聊。人物与身份分离。
- 固定九张原创哥特插画头像、原创月夜村庄背景。
- AI 发言逐字展示，默认40字/秒、停留3秒，随后自动推进。速度与停留可调。
- 你发言限时90秒，结束或超时提交输入内容；空白视为过。投票和技能等待确认。
- 暂停会停止前端推进和倒计时。进行中的一次模型请求可能继续完成，回复保存在原回合供恢复使用，避免重复调用。
- 公开发言、投票、合法可见私密信息；笔记保存在浏览器且不发送模型。
- 当前对局自动存到 `data/store.json`，重启后暂停恢复；历史保存最近50局。
- 结束后揭晓全部身份，查看事件、票型和简短决策摘要；不展示模型隐藏思维链。
- 每局重新创建角色知识，不把历史对局传给新局 AI。

## 固定规则

3狼人、3村民、1预言家、1女巫、1猎人；无警长，不设狼人自爆。

- 屠边：狼全灭好人胜；村民或神职全灭狼人胜。
- 夜间顺序：狼队密谈 → 狼队投刀 → 预言家查验 → 女巫用药 → 天亮结算。
- 狼刀按最多票决定，最高票平票为空刀；狼人不能刀队友。
- 女巫每夜最多用一药，仅首夜能自救。解药用完后不再告知刀口。
- 预言家不能重复查验同一人，结果只显示狼人/好人。
- 白天按座位发言、投票。最高票平票进入PK，平票者不参与第二次投票；再次平票或全弃票无人出局。
- 猎人被刀或被放逐可以开枪，毒死不能开枪；同夜刀毒同时命中也不能开枪。符合条件的猎人先处理开枪再判胜负。
- 首夜死亡和白天出局有遗言；已产生胜负时直接结算。
- 死亡不自动翻牌，猎人开枪公开身份。真人出局仍只能盲视角旁观，导演全知仅影响界面。

参考常见网易狼人杀流程，已确认的女巫自救等规则优先；不是网易官方客户端的完整复制。具体规则以本页及游戏内规则为准。

## 结构和接口

- `app/page.tsx`：大厅、准备、角色档案、对局、历史与设置；沿用 Sites 生成的 React/Vinext 与组件库，本地 Node 运行，不使用云存储。
- `lib/game/engine.mjs`：纯规则引擎、合法动作、胜负、每个玩家的信息投影。
- `lib/game/service.mjs`：本地存档、单次操作锁、DeepSeek 适配、预算和响应检查。
- `GET /api/game`：只返回当前观看者可见的状态、配置就绪标志与角色库，不返回密钥或隐藏身份。
- `POST /api/game`：`start`、`characters`、`pause`、`step`、`budget`、`preview`、`archive`、`replay`。`step` 携带 revision，拒绝重复/过期回合，服务端计算合法目标。
- API 校验本机 Host 与同源 Origin。单用户本机应用；本地磁盘存档包含完整身份，不以抵御电脑拥有者读取文件为目标。
- WebMCP 可用时注册「读取合法可见对局」和「暂停」工具；不支持该实验接口的浏览器照常使用界面。
